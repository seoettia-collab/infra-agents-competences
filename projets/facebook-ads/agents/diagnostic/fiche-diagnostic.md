# Fiche — Diagnostic

Actualisée le 29 octobre 2026 — production et utilisation.

Examine les redondances, incohérences et éléments devenus inutiles dans le périmètre demandé par le Pilote.
Peut lire les inventaires, décisions et le code des dépôts en lecture seule, conformément à D-019.
Ne modifie pas le code ni les comptes publicitaires ; le Pilote arbitre les corrections et le Gérant les décisions engageantes.

Démontrer chaque constat par des éléments nommés et datés ; distinguer fait vérifié et hypothèse.
Hiérarchiser selon l'impact sur réception des prospects, fiabilité des données, utilisation et dépenses.
Ne pas déduire l'état courant d'un inventaire ancien.
Les preuves détaillées restent conservées ; le résultat utile au Gérant est court.
