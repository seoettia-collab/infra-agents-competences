## 2. Ce que tu dois produire — STRATÉGIE META UNIQUEMENT

### A. Diagnostic critique de notre méthode actuelle
Identifier ce qui est probablement :
- bon et à conserver ;
- obsolète ;
- trop conservateur ;
- contre-productif ;
- impossible à juger sans données live.

Ne protège aucune ancienne décision simplement parce qu'elle existe.

### B. Nouvelles stratégies à introduire
Proposer et classer les stratégies Meta/Facebook qui peuvent réellement améliorer :
- qualité des leads ;
- coût par lead qualifié ;
- volume utile ;
- taux de prise de rendez-vous / devis ;
- stabilité de la diffusion avec petit budget.

Pour CHAQUE stratégie retenue, fournir :
1. principe exact ;
2. pourquoi elle pourrait fonctionner pour Mistral Pro Reno ;
3. prérequis ;
4. risque principal ;
5. protocole de test ;
6. KPI de décision ;
7. critère VALIDATION / ARRÊT ;
8. priorité P0 / P1 / P2.

Chercher aussi les approches contre-intuitives ou nouvelles qui méritent un test, pas
uniquement les optimisations classiques.

### C. Architecture stratégique des campagnes Meta
Définir le modèle le plus pertinent pour petit budget local rénovation IDF :
- nombre de campagnes ;
- nombre d'ad sets ;
- nombre de créas simultanées ;
- broad / ciblage / retargeting si pertinent ;
- règles d'introduction, maintien et coupure d'une créa ;
- rythme de renouvellement créatif ;
- logique budget et montée en charge ;
- cas où il faut au contraire simplifier fortement la structure.

### D. Créatives et angles
Définir une vraie stratégie de portefeuille créatif :
- angles de douleur / preuve / résultat / confiance / urgence / spécialisation métier ;
- UGC, avant-après, chantier réel, vidéo courte, statique, témoignage, preuve locale,
  selon pertinence ;
- comment différencier un nouvel angle d'une simple variation cosmétique ;
- méthode pour détecter fatigue créative vs mauvais ciblage vs mauvais formulaire.

Le but est de créer de NOUVEAUX tests intelligents, pas seulement décliner une pub existante.

### E. Formulaire Lead Ads et qualité
Définir :
- friction optimale ;
- questions qui filtrent réellement ;
- questions inutiles ou destructrices de conversion ;
- formulaire court vs plus qualifiant ;
- stratégie conditionnelle selon métier / type de chantier si pertinente ;
- comment éviter d'acheter du volume creux.

### F. Pilotage AVANT et APRÈS boucle qualité
AVANT score/CAPI fiable : quels KPI autorisent une décision, lesquels peuvent tromper ?
APRÈS score/CAPI fiable : quels signaux business doivent remplacer le CPL brut comme
métrique principale ?

### G. Plan d'expérimentation priorisé
Construire un backlog de tests P0 / P1 / P2.

Je veux savoir :

- ce qu'on change exactement ;
- combien de temps / données minimales avant lecture ;
- ce qui prouve que le test gagne ou perd.
