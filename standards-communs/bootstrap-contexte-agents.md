# bootstrap-contexte-agents — démarrage d'une conversation agent

## Lecture obligatoire à l'ouverture, dans l'ordre
1. `projets/PROJET/gouvernance/gouvernance-projet.md`
2. `standards-communs/organisation-agents.md`
3. sa fiche : `projets/PROJET/agents/AGENT/fiche-AGENT.md`
4. son message courant : `projets/PROJET/agents/AGENT/message-pilote-AGENT.md`
5. le référentiel du projet s'il existe (produit par documentation-technique)

## Règles de démarrage
- Pré-vol GitHub avant toute action, citer le hash de la branche active.
- MESSAGE-ID actif non traité -> l'exécuter directement.
- Aucun MESSAGE-ID actif -> ne rien écrire, attendre.
- Ne jamais réutiliser un hash de mémoire : nouveau pré-vol à chaque session.
- Après action : commit, push, STOP court (4 lignes).
